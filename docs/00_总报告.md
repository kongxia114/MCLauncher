## 三、这个程序大体在干什么

它就是一个"下载 + 拼命令行 + 启动 java"的壳，核心行为：

1. 首次运行 → 引导设置 Java 路径（找不到就自动下载 32/64 位 JRE）。
2. 读 `mclauncher.cfg`（INI），记住游戏名、Java 路径、最大内存、皮肤、正版登录开关。
3. 从 `s3.amazonaws.com` 拉官方版本清单 `versions.json`；从自家 `updatemc.mcsky.net` 拉整合包清单（gameupdate/forgeupdate/foupdate.ini）。
4. 下载 assets / libraries / natives / bgskin，zlib 解压到 `.minecraft`。
5. 支持"正版登录"：POST `authserver.mojang.com/authenticate`，并把登录态与官方启动器的 `launcher_profiles.json` 打通。
6. 拼出 `javaw.exe -Xincgc -Xmx… -cp … net.minecraft.client.Minecraft …`（或 1.6+ 的 `mainClass` + `${…}` 模板）并 `CreateProcessA`。
7. 自更新：查 `checkversion`，弹"发现MCLauncher新版本"，下载 `update.exe` 写 `update.bat` 自替换。
8. 带一个统计上报 `count.php` 和支付宝赞助链接。

细节见 `08_行为与接口还原.md`。

## 四、想继续深入，最短路径

1. **只想知道逻辑** → 直接看 `08`，不用开任何工具。
2. **想改标题/广告/服务器地址** → 看 `10_补丁定位表.md`，十六进制编辑器等长替换即可（无校验和、无签名）。
3. **想动态确认启动命令** → x32dbg 载入，在 `CreateProcessA` 下断，点"启动游戏"，看第二个参数（命令行）原文。这是最快拿到完整命令的办法。
4. **想逆具体函数** → IDA 载入 `原始数据/text.bin`（基址 0x400000），对 `06` 里的字符串地址按 X 找交叉引用。易语言静态编译的运行时函数无符号，但业务代码很"直"：基本都是 `lstrcpy/InternetOpenUrlA/CreateProcessA` 的连续调用。
5. **不要再用 ECodeExplorer** → 它针对 2006 年的易语言 E 格式（`WTNE` 头），本文件里没有该结构，扫不出东西（原因见 `07`）。
