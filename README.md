# MCL (MineCraft Launcher) 忘却的旋律启动器 - 经典复刻版

![Version](https://img.shields.io/badge/version-5.31-blue.svg)
![Language](https://img.shields.io/badge/language-VB.NET-purple.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

> 这一个基于 VB.NET 编写的 Minecraft 启动器经典复刻项目。致敬经典，慢慢打磨。

## 📖 项目简介

本项目是对早期经典 Minecraft 启动器（MineCraft Launcher）的 UI 与功能复刻。初衷是为了重温当年的技术架构与界面设计，同时也作为一个持续学习、慢慢完善的个人开源项目。

界面预览：

![图片](https://raw.githubusercontent.com/kongxia114/MCLauncher/master/Images/001.jpg)

## ✨ 当前进度 (Features)

- [x] 经典 UI 界面复刻（背景、按钮、下拉框布局）
- [x] 版本选择下拉框
- [x] 基础启动界面
- [ ] 离线登录 / 正版登录（待开发）
- [ ] 版本下载与自动更新（待开发）
- [ ] 内存分配与 Java 路径自动检测（待开发）
- [ ] 皮肤显示（待开发）

## 🛠️ 开发环境

- **IDE**: Visual Studio 2019 / 2022
- **语言**: Visual Basic .NET (VB.NET)
- **框架**: .NET Framework (请根据你实际使用的版本修改，如 4.8)
- **UI 框架**: WinForms

## 🚀 如何运行与编译

1. 克隆本仓库到本地：
   ```bash
   git clone https://github.com/你的用户名/你的仓库名.git
   ```
2. 进入项目目录，双击 `MCL.sln` 使用 Visual Studio 打开。
3. 等待 NuGet 包还原（如果有）。
4. 按 `F5` 或点击顶部的“启动”按钮即可编译运行。

## 🗺️ 未来计划 (Roadmap)

由于是“慢慢写”的项目，不设死线。后续计划包括：
1. 完善核心启动逻辑，兼容更多版本的 Minecraft。
